## Hello Web Server - Name Based Virtual Hosts on Apache
## x)
Last time we installed Apache on our VirtualMachine. Thanks to Apache we can have many domain names under one single ip address (name based virtual hosting) -> differs from ip based v-hosting, that requires a different ip addresses for every website (ip based v-host)

- Apache matches the request to the best <VirtualHost> based on IP address and port.
- Among those matches, Apache compares ServerName and ServerAlias to the request hostname.
- Using * in <VirtualHost *:port> makes IP-based matching irrelevant.

If no ServerName or ServerAlias matches, the first listed virtual host is used as the default.

1) 127.0.0.1 -> **Client IP address**: The IP address that made the request (127.0.0.1 = localhost)
2) [27/Jan/2026:14:19:00 +0200] → **Timestamp**: Date and time of the request. +0200 is the local time zone. Important for debugging and auditing.
3) "GET / HTTP/1.1" → **Request line**: Contains three parts:
  - GET → HTTP method
  - / → requested resource
  - HTTP/1.1 → protocol version
This request loads the main HTML page.
4) 200 → **HTTP status code**: 200 = request succeeded. Indicates the page was served correctly.
5) 3383 → **Response size (bytes)**: Size of the response body in bytes. Does not include HTTP headers. This is the HTML file size.
6) "Mozilla/5.0 (X11; Linux x86_64; rv:140.0) Gecko/20100101 Firefox/140.0" → **User-Agent**: Identifies the browser and operating system -> Linux OS -> Firefox version 140

**A single page load triggers multiple HTTP requests:**
1) First request : main page
2) Second request : embedded image
3) Third request : favicon

Apache access logs include:
- Client IP
- Timestamp
- Request line
- Status code
- Response size
- Referer
- User-Agent

## d) 
*curl*: fetches the page content. Sends an HTTP GET request and prints the response body. With this command we can fast see what we wrote on the HTML5 code.
![Sieppaa25](https://github.com/user-attachments/assets/cf647369-548c-4b07-8306-744585cb321b)

*curl -I*: HEAD request. -I sends a HTTP HEAD request which returns only headers at response.
![Sieppaa26](https://github.com/user-attachments/assets/43cffaa7-a5c8-46bb-ad6e-1208ccfefc19)
**HTTP/1.1 200 OK**: HTTP protocol version and status code. 200 OK means the request succeeded.
**Date**: Time when the server generated the response.
**Server**: Web server software and version.
**Last-Modified**: Timestamp of the last modification of the resource.
