## h5 - Nimekäs

**a) Julkinen nimi verkkopalvelimelle**

- Ostin domainin Namecheapilta, sillä se osoittautui tunnilla yhteenvedon jälkeen, luotettavaksi ja samalla suhteellisen edulliseksi palveluntarjoajaksi.
- Etsin siis vapaan domainin ja sieltä löytyikin ihan omalla nimellä höystetty *alvarmanfe.com* vapaana.
- Ostin vuoden mittaiset oikeudet domainin tältä erää. Todennäköisesti käyn myöhemmin ostamassa tälle lisää aikaa.
- Tarkistan Domain-sivulta, että Nameserves kohdassa on valittuna NameCheap BasicDNS, joka taisi olla jo oletuksena valmiina.

![Sieppaa40](https://github.com/user-attachments/assets/8bc3ba6a-3f12-4591-9178-5f0274b6d3c5)

- Siten menen Advanced DNS asetuksiin ja lisäätään Host Records:eissa A Record kohtaan oma julkinen IP, johon domain osoitetaan ja CNAME Record kohtaan oma domain nimi joka juuri ostettiin eli *alvarmanfe.com*. Tallensin tiedot ja jäin odottamaan hetken, että DNS päivittyy (yleensä kesto voi vaihdella 5 - 30 minuttiin).

![Sieppaa](https://github.com/user-attachments/assets/27b9eae2-bfb7-46a6-915d-b618aaae7b34)

Aloitin luomalla palvelimelleni uuden Name-based virtual hostin komennolla:

```sudoedit /etc/apache2/sites-available/alvarmanfe.conf```

Lisäsin uuteen .conf tiedostoon alla olevat tiedot:

```
<VirtualHost *:80>
 ServerName alvarmanfe.com
 ServerAlias www.alvarmanfe.com
 DocumentRoot /home/alvar/publicsites/alvarmanfe.com
 <Directory "/home/alvar/publicsites/alvarmanfe.com">
   Require all granted
 </Directory>
</VirtualHost>```
```

Luotuani .conf tiedoston, loin vielä kansiot polkuun jotka .conf tiedostossa mainitsin poluksi sekä kytkin sivunn päälle ja käynnistin apachen uudelleen.

```
cd

mkdir public-sites

cd public-sites

mkdir alvarmanfe.com

cd alvarmanfe.com

sudo a2ensite alvarmanfe.com.conf

sudo a2dissite 000-default.conf

sudo systemctl restart apache2
```

- Sitten loin index.html tiedoston alvarmanfe.com-kansioon komennolla nano index.html, johon lisäsin tekstiksi Kokeillaan jotta pystyin testaamaan sivun toiminnan.
- testasin sen toimintaa komennolla curl alvarmanfe.com, joka palautti jo tutuksi tulleen 403 Forbidden sivun, joten selvitin vian lokeista syottämällä ```sudo tail -1 /var/log/apache2/error.log```

- Käytin komentoa ```ls -la /home/alvar/public-sites/``` tarkastellakseni oikeuksia.
- Virhe löytyikin näistä tiedostoista
- Käytin komentoa ```chmod go+x /home/alvar/``` lisääkseni ryhmille group (g) ja others (o) execute (+x) -oikeudet ja tarkastin uudelleen kansion oikeuksia.
- Tämän jälkeen päivitin uudestaan oman sivuni syöttäen index.html "Kokeillaan uudestaan" ja näytti oikealta tällä kertaa.
